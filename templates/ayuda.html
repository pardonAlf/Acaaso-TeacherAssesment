¿Qué es TeacherAssessment?

TeacherAssessment es una plataforma diseñada para crear, aplicar y analizar evaluaciones de forma automática. Permite a los profesores generar quizzes en minutos, compartirlos mediante un código y obtener resultados inmediatos sin necesidad de corrección manual.

El objetivo es reducir el tiempo de evaluación y mejorar la toma de decisiones mediante análisis de resultados en tiempo real.

¿Cómo crear un Quiz?

1. Crear un nuevo Quiz

Accede al módulo de creación y define el nombre del quiz, número de preguntas y tipo de evaluación.

2. Elegir la forma de creación

Puedes crear preguntas de diferentes formas:

  • ✔ Manual: escribiendo cada pregunta
  • ✔ Con IA: el sistema genera preguntas automáticamente
  • ✔ Desde archivo: subiendo un documento
  • ✔ Desde texto: pegando contenido para generar preguntas

3. Configurar el Quiz

Define si el alumno puede ver respuestas, número de intentos y otras opciones disponibles.

4. Guardar y activar

Una vez configurado, guarda el quiz para que esté disponible para los alumnos.

1. Crear Quiz

Diseña preguntas fácilmente o usa inteligencia artificial.

2. Compartir código

Los alumnos ingresan con un código único.

3. Resolver

Responden el quiz y reciben su nota al instante.

4. Analizar

Visualiza resultados y mejora el aprendizaje.
